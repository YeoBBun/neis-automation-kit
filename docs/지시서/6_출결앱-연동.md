# 출결 앱 파일로 학생 출결 넣기 (구글 캘린더 없이)

> 이 문서는 **클로드에게 주는 지시서**입니다. 선생님이 읽으실 필요는 없습니다.
> 「1. 학생 출결」(구글 캘린더 방식)과 나이스에 넣는 부분은 똑같고, **출결을 읽어오는 곳만** 다릅니다.

선생님은 출결을 **출결 앱**(https://yeobbun.github.io/attendance/)에 매일 입력해.
앱의 「출결 기록 → 나이스 파일」 을 누르면 `attendance_neis_시작일-종료일.json` 파일이
**다운로드 폴더**에 저장되고, 이 폴더의 `app_to_neis.py` 가 그 파일을 읽어 키트의 `main.py` 로 나이스에 넣어.
구글 캘린더·구글 열쇠(oauth_client.json)는 **필요 없어.**

★ 이 지시서에서도 [시작하기.md](../../시작하기.md) 의 «일하는 방식»(한 번에 한 단계, 먼저 묻기,
명령 모양, 학생 이름을 대화에 길게 나열하지 않기)을 그대로 지켜.

## 단계

  1단계   설치하기 (.\setup.ps1 한 번) — 이미 했으면 건너뛴다
  2단계   설정 마법사 — 학년·반·인증서. **6번(구글 캘린더)은 n 으로 건너뛴다**
  3단계   파일 받기 — 선생님께 앱에서 「나이스 파일」을 저장해 달라고 한다
  4단계   연습 — 목록만 보기 (나이스는 안 연다)
  5단계   진짜로 넣기
  6단계   나이스 화면에서 눈으로 확인하고, 파일 지우기

### 1단계 — 설치하기

[1_나이스-학생출결.md](1_나이스-학생출결.md) 의 1단계와 똑같아. `.\setup.ps1` 한 번.

### 2단계 — 설정 마법사

    .\.venv\Scripts\python.exe -X utf8 setup_wizard.py

마법사가 새 창에서 학교·학년·반·인증서를 물어봐. 선생님이 거기에 직접 넣으셔.
**「6. 학생 출결 자동화 (구글 캘린더)」에서는 n** 을 누르시라고 미리 말씀드려.

### 3단계 — 파일 받기

선생님께 이렇게 안내해.

- 크롬에서 출결 앱을 열고 「출결 기록」 탭 → **나이스 파일** → 기간 확인 → **파일 저장**
- 파일은 다운로드 폴더에 저장돼. 옮기지 않아도 돼

### 4단계 — 연습 (목록만)

    .\.venv\Scripts\python.exe -X utf8 app_to_neis.py --dry-run

- 가장 최근의 `attendance_neis_*.json` 을 다운로드 폴더에서 찾아 읽어
- 「자동으로 못 넣는 건」(결과, 교시 없는 지각·조퇴)은 선생님이 나이스에서 직접 넣으셔야 한다고 알려줘
- 목록을 «건수로» 요약해서 보여주고 다음으로 갈지 물어봐

### 5단계 — 진짜로 넣기

    .\.venv\Scripts\python.exe -X utf8 app_to_neis.py

- 미리 접수한 체험학습처럼 **미래 날짜**도 넣으려면 `--future` — 선생님이 원하실 때만
- 그 뒤 동작·실패 표시(❌ ❓)·저장 방식은 [1_나이스-학생출결.md](1_나이스-학생출결.md) 와 같아

### 6단계 — 확인

- 나이스 화면에서 넣은 날짜를 눈으로 확인하시라고 해. 마감은 선생님이 하셔
- 다 됐으면 `attendance_neis_*.json` 파일을 지울지 여쭤봐 (학생 이름·출결이 들어 있다). 좋다고 하실 때만 지워

다음부터는 선생님이 **"앱 출결 나이스에 넣어줘"** 또는 **`/앱출결`** 이라고만 하시면 4~6단계를 하면 돼.
