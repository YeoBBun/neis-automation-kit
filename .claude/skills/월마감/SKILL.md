# 월 출결마감 — 한 마디로 끝까지

자세한 설명·첫 준비는 [docs/지시서/5_나이스-월마감.md](../../../docs/지시서/5_나이스-월마감.md). 여기는 매달 순서만.

명령은 한 줄씩, 이 모양 그대로 (앞에 `&`·`$env:`·`cd` 금지). 학교 밖이면 나이스를 여는 1·2단계를
`.\.venv\Scripts\python.exe -X utf8 run_vpn.py --minutes 8 -- python <스크립트> <옵션>` 으로 감싼다.

달은 선생님 말에서 정한다 («10월» → `2026-10`). 연도는 코드로 확인한다 (1·2월은 다음 해).

| 단계 | 명령 | 통과 기준 |
|---|---|---|
| 1 맞추기 | `.\.venv\Scripts\python.exe -X utf8 verify_attendance.py 2026-10-01 2026-10-31` (빠짐만 있으면 `main.py <가장 이른 빠짐 날짜>` 후 다시 대조) | «전부 일치합니다». 분류다름·교시다름·추가가 남으면 **마감하지 말고** 선생님께 보여드린다 |
| 2 마감+받기 | `.\.venv\Scripts\python.exe -X utf8 month_close.py 2026-10 --close --download` | RESULT_JSON `ok:true` · 월마감 «마감됨» · 파일 2개 |
| 3 근태 보기 | `.\.venv\Scripts\python.exe -X utf8 geuntae.py 2026-10` | 새로 넣을 줄 표를 보여드리고 «써도 될까요?» |
| 4 근태 쓰기 | `.\.venv\Scripts\python.exe -X utf8 geuntae.py 2026-10 --write` | «✅ … 모두 머리글과 맞습니다» |
| 5 인쇄 | `.\.venv\Scripts\python.exe -X utf8 print_month.py 2026-10 --print` | printed 3개 · 선생님께 «몇 장 나왔는지» 확인 |

**출결 앱을 쓰는 선생님** (구글 캘린더 없음): 1단계를 이렇게 바꾼다 —
선생님께 앱에서 «그 달 1일~말일» 로 나이스 파일을 받아 달라고 한 뒤
`.\.venv\Scripts\python.exe -X utf8 app_to_neis.py <그 파일 전체 경로> --마감`
— 크롬을 **한 번만** 열고 날짜마다 «파일과 다른 것 넣기·고치기 → 저장 → 다시 읽어 확인 → 그날 [출결마감] → 다음 날» 을 한다.
따로 하던 `--대조` 는 하지 않는다 (넣기 전에 화면을 읽어 비교하고, 저장 뒤 다시 읽는다).
통과 기준: 출력에 ❌·❓ 가 없고 날마다 «저장 뒤 다시 읽어 보니 파일과 같습니다» 또는 «이미 파일과 같습니다».
**❌·❓ 가 하나라도 있으면 2단계로 가지 않는다** — 2단계의 일마감은 남은 날을 한꺼번에 마감하므로 틀린 날까지 마감된다.
2단계는 같다 (1단계에서 마감된 날은 건너뛴다). 3·4단계(근태 색인 목록)는 구글 캘린더를 읽으므로 **출결 앱 방식에서는 아직 안 된다** — 건너뛰고 그렇게 말씀드린다.

- 같은 학생이 같은 날 두 건(결과+조퇴 등)이면 키트는 넣지 않고 ✋ 로 알린다 — 선생님이 직접 넣는다. 그 줄이 비어 있으면 ❌ 로 나오고 그날은 마감되지 않는다. 선생님이 넣으신 뒤 같은 명령을 다시 돌리면 그날을 마감한다. 칸이 비었는지만 보므로 한 건만 차 있어도 넘어간다 → ✋ 가 있던 달은 2단계 전에 `app_to_neis.py <파일> --대조` 를 돌려 그 줄까지 확인한다
- `app_to_neis.py` 에는 `--help` 가 없다. 모르는 옵션을 붙이면 **그대로 실제 입력이 돈다** (2026-11-02 실수로 한 번 돌았다). 옵션은 파일 맨 위 설명을 읽어서 본다
- 나이스는 파일 내려받기가 시작되면 창을 스스로 닫는다 → 2단계는 파일마다 크롬을 다시 연다 (정상)

- 그 달 마지막 평일 전이면 2단계가 스스로 멈춘다. 억지로 `--force` 를 붙이지 않는다 (선생님이 원하실 때만)
- **달 중간까지 마감** («13일 기준으로 월마감»): 나이스 월마감 화면의 «마감일» 칸을 그날로 바꾸면 그날까지 마감된다.
  `.\.venv\Scripts\python.exe -X utf8 month_close.py 2026-11 --close --마감일 13`
  - 이 옵션은 일마감 [전체선택] 을 누르지 않는다 (누르면 뒤의 날까지 일마감된다) → 그날까지의 일마감은 먼저 `app_to_neis.py --마감` 으로
  - 나이스 확인창: 「11월 출결자료가 13일까지 마감됩니다. 마감하시겠습니까?」 → 확인. 끝나면 표 칸에 «2026.11.13.» 이 찍힌다 (마감일 칸은 다시 읽으면 30 으로 보인다)
  - 2026-11-13 실측으로 마감했다 (스니펫으로 누름). 스크립트의 이 경로를 처음부터 끝까지 돌려 본 적은 아직 없다
- 3단계의 ⚠️ 줄(겹침·나이스와 다름·추정)은 하나씩 짚어 드린다
- 한글 파일은 **geuntae.py 로만** 고친다. 한글 MCP 의 replace/fill 은 .hwp 를 깨뜨린다
- 학생 이름은 스크립트가 가려서 찍은 그대로만 보여 드린다
- 끝나면 3~5줄 정리: 마감 여부 · 근태 몇 줄 · 인쇄 몇 쪽 · 남은 일(기안문 상신은 담임 화면에 없다)
