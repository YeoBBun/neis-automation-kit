# 월 출결마감 — 한 마디로 끝까지

자세한 설명·첫 준비는 [docs/지시서/5_나이스-월마감.md](../../../docs/지시서/5_나이스-월마감.md). 여기는 매달 순서만.

명령은 한 줄씩, 이 모양 그대로 (앞에 `&`·`$env:`·`cd` 금지). 학교 밖이면 나이스를 여는 1·2단계를
`.\.venv\Scripts\python.exe -X utf8 run_vpn.py --minutes 8 -- python <스크립트> <옵션>` 으로 감싼다.

달은 선생님 말에서 정한다 («10월» → `2026-10`). 연도는 코드로 확인한다 (1·2월은 다음 해).

| 단계 | 명령 | 통과 기준 |
|---|---|---|
| 1 맞추기 | `.\.venv\Scripts\python.exe -X utf8 verify_attendance.py 2026-10-01 2026-10-31` (빠짐만 있으면 `main.py <가장 이른 빠짐 날짜>` 후 다시 대조) | «전부 일치합니다». 분류다름·교시다름·추가가 남으면 **마감하지 말고** 선생님께 보여드린다 |
| 2 마감+받기 | `.\.venv\Scripts\python.exe -X utf8 month_close.py 2026-10 --close --download` | RESULT_JSON `ok:true` · 월마감 «마감됨» · 파일 2개 |
| 3 근태 보기 | `.\.venv\Scripts\python.exe -X utf8 geuntae.py 2026-10` | 새로 넣을 줄 표를 보여드리고 «써도 될까요?» |
| 4 근태 쓰기 | `.\.venv\Scripts\python.exe -X utf8 geuntae.py 2026-10 --write` | «✅ … 모두 머리글과 맞습니다» |
| 5 인쇄 | `.\.venv\Scripts\python.exe -X utf8 print_month.py 2026-10 --print` | printed 3개 · 선생님께 «몇 장 나왔는지» 확인 |

**출결 앱을 쓰는 선생님** (구글 캘린더 없음): 1단계를 이렇게 바꾼다 —
선생님께 앱에서 «그 달 1일~말일» 로 나이스 파일을 받아 달라고 한 뒤
`.\.venv\Scripts\python.exe -X utf8 app_to_neis.py --대조` (빠짐이 있으면 `app_to_neis.py` 로 넣고 다시 대조).
2단계는 같다. 3·4단계(근태 색인 목록)는 구글 캘린더를 읽으므로 **출결 앱 방식에서는 아직 안 된다** — 건너뛰고 그렇게 말씀드린다.

- 그 달 마지막 평일 전이면 2단계가 스스로 멈춘다. 억지로 `--force` 를 붙이지 않는다 (선생님이 원하실 때만)
- 3단계의 ⚠️ 줄(겹침·나이스와 다름·추정)은 하나씩 짚어 드린다
- 한글 파일은 **geuntae.py 로만** 고친다. 한글 MCP 의 replace/fill 은 .hwp 를 깨뜨린다
- 학생 이름은 스크립트가 가려서 찍은 그대로만 보여 드린다
- 끝나면 3~5줄 정리: 마감 여부 · 근태 몇 줄 · 인쇄 몇 쪽 · 남은 일(기안문 상신은 담임 화면에 없다)
