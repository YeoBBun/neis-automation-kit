# 출결 앱 파일 → 나이스 입력

구글 캘린더 대신 **출결 앱에서 내보낸 파일**을 읽어 나이스에 넣는다.
나이스에 넣는 부분은 키트의 `main.py` 를 그대로 쓴다 ([[나이스출결]] 스킬과 같은 동작).

## 순서

1. 파일 확인 — 이 폴더나 다운로드 폴더에 `attendance_neis_*.json` 이 있는지 본다.
   없으면 선생님께 "앱 「출결 기록 → 나이스 파일」에서 저장해서 PC 다운로드 폴더로 옮겨 주세요" 라고 안내한다.
2. **먼저 목록만** 본다 (나이스를 열지 않는다):

   ```powershell
   .\.venv\Scripts\python.exe -X utf8 app_to_neis.py --dry-run
   ```

   - 맨 위 「자동으로 못 넣는 건」(결과, 교시 없는 지각·조퇴)은 선생님이 나이스에서 직접 넣어야 한다고 알린다.
   - 목록을 보여주고 "이대로 나이스에 넣을까요?" 하고 묻는다. 학생 이름을 길게 다시 나열하지는 않는다.
3. 선생님이 좋다고 하면 실제로 넣는다:

   ```powershell
   .\.venv\Scripts\python.exe -X utf8 app_to_neis.py
   ```

   - 미래 날짜(미리 접수한 체험학습 등)도 넣으려면 `--future` 를 붙인다. 선생님이 원할 때만.
   - **선생님이 «마감까지» 라고 말했을 때만** `--마감` 을 붙인다 (평소엔 저장까지만).
     저장이 확실하고 ❌·❓ 가 없는 날만 [출결마감] 을 누른다. 「변경된 내용이 없습니다」 인 날도 마감하지 않는다.
     마감은 그날 반 전체를 확정한다 — 실행 전에 이 점을 한 줄 말씀드린다.
     «예상과 다른 창» 으로 멈추면 그 창을 누르지 말고 글자를 선생님께 보여드린다.
   - 특정 파일을 쓰려면 파일 경로를 인자로 준다.
4. 끝나면 실패(❌·❓)가 있는지 알려 주고, **나이스 화면에서 눈으로 확인**하시라고 한다.
5. 다 넣었으면 파일을 지울지 묻는다 (학생 이름과 출결이 들어 있다). 선생님이 좋다고 할 때만 지운다.

## 주의

- 학교 밖이면 키트 안내대로 `run_vpn.py` 로 감싼다.
- 마감된 날은 셀이 안 눌린다 — [[나이스출결]] 스킬의 「고칠 때」 를 따른다.
