# 출결 앱 파일 → 나이스 입력

구글 캘린더 대신 **출결 앱에서 내보낸 파일**을 읽어 나이스에 넣는다.
나이스에 넣는 부분은 키트의 `main.py` 를 그대로 쓴다 ([[나이스출결]] 스킬과 같은 동작).

## 순서

1. 파일 확인 — 이 폴더나 다운로드 폴더에 `attendance_neis_*.json`(또는 `.txt`) 이 있는지 본다.
   (`.txt` 는 휴대폰 앱에서 「드라이브로 보내기」 로 보낸 것을 구글 드라이브 웹에서 내려받은 파일 — 내용은 같다)
   없으면 선생님께 "앱 「출결 기록 → 나이스 파일」에서 저장해서 PC 다운로드 폴더로 옮겨 주세요" 라고 안내한다.
2. **먼저 목록만** 본다 (나이스를 열지 않는다):

   ```powershell
   .\.venv\Scripts\python.exe -X utf8 app_to_neis.py --dry-run
   ```

   - 맨 위 「자동으로 못 넣는 건」(결과, 교시 없는 지각·조퇴)은 선생님이 나이스에서 직접 넣어야 한다고 알린다.
   - 목록을 보여주고 "이대로 나이스에 넣을까요?" 하고 묻는다. 학생 이름을 길게 다시 나열하지는 않는다.
3. 선생님이 좋다고 하면 실제로 넣는다:

   ```powershell
   .\.venv\Scripts\python.exe -X utf8 app_to_neis.py
   ```

   - **파일이 기준이다.** 파일 기간(from~to) 안에서 나이스에 이미 들어간 출결이 파일과 다르면 지우고 파일대로
     다시 넣고(✏️), 파일에 없는 출결은 지운다(🧹 — 「깨끗이」 체크박스). 같은 학생은 건드리지 않는다.
     **이미 [출결마감] 한 날이 다르면 [마감취소] → 고치기 → 저장 뒤 다시 읽어 확인 → 다시 [출결마감]** 까지 한다
     (`--마감` 이 없어도 — 원래 마감돼 있던 날이므로). 못 고치면 다시 마감하지 않고 «마감이 풀린 채로 남음» 으로 알린다.
     월마감이 된 달이면 일마감취소가 막힐 수 있다 — 그때는 멈추고 나이스 글자를 보여 준다(월마감 취소는 아직 코드 없음).
     마감취소 창 글자는 아직 실측 안 됨 — «취소 … 하시겠습니까» 가 아닌 창이면 누르지 않고 멈춘다.
     무엇이 바뀔지 미리 보려면 `--대조` (읽기 전용 — 「추가」 = 지워질 것, 「분류다름」·「교시다름」 = 고쳐질 것).
     예전처럼 넣기만 하려면 `--추가만`. 사유 칸만 다른 것은 아직 못 찾는다.
   - 미래 날짜(미리 접수한 체험학습 등)도 넣으려면 `--future` 를 붙인다. 선생님이 원할 때만.
   - **선생님이 «마감까지» 라고 말했을 때만** `--마감` 을 붙인다 (평소엔 저장까지만).
     저장이 확실하고 ❌·❓ 가 없는 날만 [출결마감] 을 누른다. 「변경된 내용이 없습니다」 인 날도 마감하지 않는다.
     마감은 그날 반 전체를 확정한다 — 실행 전에 이 점을 한 줄 말씀드린다.
     «예상과 다른 창» 으로 멈추면 그 창을 누르지 말고 글자를 선생님께 보여드린다.
   - 특정 파일을 쓰려면 파일 경로를 인자로 준다.
4. 끝나면 실패(❌·❓)가 있는지 알려 주고, **나이스 화면에서 눈으로 확인**하시라고 한다.
5. 다 넣었으면 파일을 지울지 묻는다 (학생 이름과 출결이 들어 있다). 선생님이 좋다고 할 때만 지운다.

## 매일 자동으로 (작업 스케줄러)

선생님이 «매일 자동으로», «예약해줘» 라고 하면:

1. 몇 시에 돌릴지 여쭤본다 (그 시각에 PC가 켜져 있고 **윈도우에 로그인돼 있어야** 한다 — 크롬 화면을 띄워 나이스를 조작하므로).
2. 등록한다 (평일만):

   ```powershell
   .\.venv\Scripts\python.exe -X utf8 app_to_neis.py --예약 16:30
   ```

3. 예약된 실행(`--auto`)이 하는 일:
   - 다운로드 폴더·이 폴더에서 **아직 넣지 않은** 출결 파일만 모아 한 번에 넣는다. 새 파일이 없으면 아무것도 안 한다.
   - 저장까지만 한다 (마감은 하지 않는다 — 선생님이 나이스에서 확인하고 마감).
   - 다 넣으면 파일을 지운다. 못 넣은 건이 있으면 파일을 남긴다.
   - 결과는 `%LOCALAPPDATA%\neis-automation\app_runs\` 의 날짜시각.log 에 남는다 (학생 이름이 있으니 저장소 안으로 옮기지 않는다).
4. 선생님이 «결과 보여줘» 하면 가장 최근 log 를 읽고 **건수와 실패만** 요약한다 (이름을 길게 나열하지 않는다).
5. 지우기: `.\.venv\Scripts\python.exe -X utf8 app_to_neis.py --예약해제`
6. 미리 보기: `--auto --dry-run` (넣지 않고, 파일도 지우지 않는다)

## 주의

- 학교 밖이면 키트 안내대로 `run_vpn.py` 로 감싼다.
- 마감된 날은 셀이 안 눌린다 — [[나이스출결]] 스킬의 「고칠 때」 를 따른다.
